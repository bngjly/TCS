# 🐍 贪吃蛇 · Snake Game

一个拥有现代赛博朋克风格（Cyberpunk Style）视觉效果的经典贪吃蛇游戏。本项目采用原生 HTML5 Canvas 和 JavaScript 开发，无需任何构建工具即可运行。

## ✨ 特性 (Features)

- **经典玩法**：使用方向键控制蛇移动，吃掉食物获得分数，撞墙或撞自身游戏结束。
- **视觉升级**：
  - **卡通蛇头**：使用 SVG 渲染的可爱蛇头，拥有动态眼睛和舌头，并随移动方向旋转。
  - **精致食物**：高保真 SVG 红苹果食物，带有光影和立体感。
  - **动态背景**：流动的光球背景，营造沉浸式氛围。
- **用户系统**：
  - 支持 **注册/登录**（数据存储在本地 LocalStorage）。
  - **游客模式**：无需登录即可快速开始游戏。
- **数据记录**：
  - **最高分**记录。
  - **历史战绩**：记录每次游戏的日期、得分和时长。
- **响应式设计**：适配桌面端和移动端（包含虚拟方向键）。

## 🚀 如何运行 (How to Run)

本项目主要是一个静态网页应用，您可以直接在浏览器中打开：

1. 克隆或下载本项目代码。
2. 双击打开 `index.html` 文件。
3. 或者使用 VS Code 的 `Live Server` 插件运行以获得最佳体验。

## 🎮 操作指南 (Controls)

### 桌面端 (Desktop)
- **⬆ 上箭头 / W**：向上移动
- **⬇ 下箭头 / S**：向下移动
- **⬅ 左箭头 / A**：向左移动
- **➡ 右箭头 / D**：向右移动
- **空格键**：暂停/继续

### 移动端 (Mobile)
- 点击屏幕下方的虚拟方向键进行控制。

## 🛠️ 技术栈 (Tech Stack)

- **HTML5 Canvas**：核心游戏渲染。
- **Vanilla JavaScript (ES6+)**：游戏逻辑与交互。
- **CSS3**：UI 样式、动画与 Flexbox 布局。
- **SVG**：矢量图形资产（蛇头、食物）。
- **LocalStorage**：用户数据与游戏记录持久化。
